# KOV Career Agency mobile app

This project packages the existing KOV Career Agency website for Android and iOS using Capacitor.

## Product scope

- The app opens `https://www.kovcareeragency.org` in a native Android/iOS web view.
- It uses the existing website, pages, navigation, forms, links, content and backend.
- No second content system, new login, new portal or replacement website is created.
- Website changes appear in the app from the same live domain. No app-store release is needed for ordinary website content changes.
- An offline/connection error screen is provided by the local app bundle.

## Build locally

Requirements: Node.js 22+, Android Studio/JDK 21 for Android, and macOS with Xcode 26+ for iOS.

```sh
cd mobile
npm install
npm run validate
npm run cap:add:android
npm run cap:add:ios
npx cap sync
```

Android debug APK:

```sh
npm run build:android:debug
```

iOS Simulator build:

```sh
npm run build:ios:simulator
```

Native folders are generated by Capacitor during the build and are not committed. The GitHub Actions workflow builds both platforms from this source.

## Distribution requirements

- Android internal testing can use the debug APK artifact. A Google Play release needs a persistent upload keystore and Play Console access.
- A distributable iPhone build needs Apple Developer signing credentials, provisioning, and App Store Connect/TestFlight access. The CI simulator build is for compilation/testing, not iPhone installation.
- Do not commit signing certificates, provisioning profiles, API keys, or keystores. Add them as repository Actions secrets when a signed release is prepared.

## App Store review limitation

This app intentionally mirrors the existing website because that is the requested scope. Apple guideline 4.2 requires an app to provide value beyond a repackaged website, so App Store approval is not guaranteed for this deliberately simple wrapper. This implementation does not add features or pages to try to influence that review.

## Website ownership and security

The app only loads the HTTPS KOV domain. It does not weaken Cloudflare, website robots/noindex directives, or existing server-side account protections. The embedded web content is always the current content served by the existing website.
