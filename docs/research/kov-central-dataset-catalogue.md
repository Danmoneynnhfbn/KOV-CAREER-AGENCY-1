# KOV central dataset catalogue

The published discovery graph is generated by `scripts/build-jsonld.js` during the Cloudflare Pages build.

Public endpoint:
- `https://www.kovcareeragency.org/data/kov-dataset-catalog.jsonld`

The catalogue has three parent collections and eighteen dataset entries:

## Professional & Employment (12)
- Professional audiences
- Job titles
- Occupations
- Industries
- Skills
- Qualifications
- Professional synonyms and related terms
- Job functions
- Seniority levels
- Employment types
- Career challenges
- Career-search intents

## Career Knowledge & Resources (2)
- FAQs
- Languages

## Global & Organisational References (4)
- Countries
- Cities
- Towns and localities
- Institutions

Every indexable public page references the same root catalogue using one JSON-LD `@id` reference. Dataset records are stored in the central file rather than repeated in each page's HTML head.

The source arrays remain in their existing files. The generator validates each array, preserves its records, checks the three group memberships and eighteen dataset entries, and verifies that public descriptions contain no internal row-count targets or validation notes.

The individual `/data/catalogues/*.json` endpoints remain available for compatibility with existing consumers.
